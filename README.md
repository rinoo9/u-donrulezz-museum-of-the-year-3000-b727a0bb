Entry for the make.fun bounty **Museum of the Year 3000**: one line, the museum label a museum in the year 3000 places next to an ordinary object from today — a smoke detector, misread as a ceiling oracle that screamed whenever food was cooked and was honoured by having its batteries removed.

> Ceiling oracle, c. 2024. It screamed whenever food was cooked; families honoured it by removing its batteries.

Run it: `python3 main.py`

The program is deterministic: it writes the same line to `/output/entry.txt` (and prints it) on every run, with no input, randomness, or network access.
